## About

I break things first, then build the control that stops the next person doing it. Most of my work sits where the attacking and the defending hand over to each other.

| Side | What that means in practice |
| --- | --- |
| Offense | Web, network and Active Directory pentesting, **bug bounty**, CTF, **reverse engineering** |
| Defense | SOC fundamentals, **threat modeling** and risk assessment on **NIST CSF** and **NIST SP 800-30** |
| Build | Security tooling in **.NET and C#**, REST APIs, full-stack web, ML work in PyTorch and pandas |

Specialties: **web exploitation** (XSS, SQLi, IDOR, CSRF, SSRF), **privilege escalation**, **DNS and email hardening** (SPF, DKIM, DMARC, DNSSEC).

**Top 8% on TryHackMe** at 16. Open to CTF teams and open-source security work.
